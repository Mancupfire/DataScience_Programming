## Data cleaning and EDA
This folder contains the data cleaning and EDA for the air quality health impact data.

### Data cleaning
The data cleaning is done in the file `data_cleaning.ipynb`. And the output is saved in the file `cleaned_dataset.csv`. File `cleaned_dataset.csv` is stored in the Training Model folder for training the model.

### EDA
The EDA is done in the file `IAQ_Analysis.ipynb`.
